# Disaster Detection App

A React Native / Expo mobile application designed for real-time disaster detection, telemetry data logging, reporting, and hazard alert management.

## Features
- **Real-time Map Visualizations**: Shows reported hazards and disaster markers.
- **Offline Mode Support**: Reports are queued locally when internet connection is down, and auto-submitted when online.
- **AI-Assisted Verification**: Submissions are parsed and scored using automated metrics for validation.
- **Interactive Reports**: Users can upload images, report hazards, and check warnings.

## Installation
Ensure you have Node.js and the Expo CLI installed. Then, follow these steps:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Expo development server:
   ```bash
   npm run start
   ```
